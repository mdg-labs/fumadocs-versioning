---
title: Agent skill
description: Teach AI coding agents how to use fumadocs-versioning.
---

If an AI coding agent (Claude Code, Cursor and others) works on your docs, install the fumadocs-versioning skill:

```bash
npx skills add mdg-labs/fumadocs-versioning --skill fumadocs-versioning
```

It tells the agent:

- how to wire the package into a Fumadocs project
- when to cut a version
- where doc fixes go: current docs or snapshots
- why to use relative links
- what each build error means

The skill is a single file, [`skills/fumadocs-versioning/SKILL.md`](https://github.com/mdg-labs/fumadocs-versioning/blob/main/skills/fumadocs-versioning/SKILL.md).
